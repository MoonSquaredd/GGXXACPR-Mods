- Lovenus Survival Mode -
by: lovenus

Version: 0.2

Adds cool stuff to survival mode, such as:
- Kliff and Justice can be fought before Darkside.
- Enemies can pick any palette instead of the same usual 4.
- Some cool side-effects when time travelling.

!! THIS MOD REQUIRES GEAR LOADER !!

Instructions:
Simply extract the .zip to your GGXXACPR main folder.
